# 知识点总览

站内 37 个内容页是分散的调研产出，按章节各讲一块。这组文档把它们收拢成一张体系表：同一个知识点可能横跨好几章，这里按「概念—来源—场景—坑」重新编排，方便按主题通读或按条目回查。

## 盘点口径

来源分三层，可信度不同，标注也不同：

- **站内页面**：37 个内容页的正文，是调研主体。每条知识点都交叉链接回原页，点击可核对。
- **官方文档**：页面里出现过的 PEP 编号、`docs.python.org` 章节、工具官方站点。链接可访问即视为实证。
- **书籍对照**：站内页面没有引用任何书籍，书目一节是编者按主题对照整理的阅读清单，十本书的版本、目录与作者信息已逐本对照官方或作者页面核实，映射关系按各书实际目录范围标注。

凡无法核实来源的说法，一律标「来源未考」，不硬凑出处。

## 怎么用

按主题通读，从「核心概念」进；遇到具体选择（用线程还是进程、要不要上 dataclass），翻「应用场景」的决策段；写代码前扫一眼「常见坑」，能省掉大半调试时间；要读源码或查规范，「官方文档」给了逐条出处。

概念与坑有大量重叠——同一个机制，正着说是概念，反着说是坑。两边都留了，方便从任一方向查。
